# 행사 사진 폴더

`다가오는 주요 행사` 카드 배경에 쓰는 사진을 여기에 둡니다.

## 넣는 방법
1. 사진 파일을 이 폴더에 저장합니다. 예: `ces-2027.jpg`
2. `public/data/exhibitions.json` 의 해당 행사 항목에서 `image` 를 채웁니다.

   ```json
   { "name": "CES 2027", "image": "public/exhibitions/ces-2027.jpg", ... }
   ```

3. 끝입니다. 배포 설정(`vercel.json`)에는 이 폴더가 이미 등록돼 있습니다.

## 규칙
- `image` 가 비어 있으면 분야 색 배너 + 행사명 이니셜로 대신 보여 줍니다(지금 상태).
- 사진 로드에 실패해도 같은 배너로 되돌아가므로 카드가 깨지지 않습니다.
- 가로로 넓은 사진이 좋습니다(카드 사진 칸 비율이 약 4:1.6).
- ★ 저작권이 있는 사진을 쓰지 마십시오. 주최측이 배포한 홍보용 이미지이거나
  직접 촬영한 사진, 또는 사용 허가를 받은 것만 넣으십시오.
